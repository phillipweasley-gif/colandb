Decisions made overnight, for the owner to confirm

  1. Members only. Posts and photos are never public and never indexed; each post is "All members" or "My connections" (members in an active dynamic with you).
  2. Posts: text up to 2,000 characters and up to 4 photos (re-encoded, location data removed). Optionally tag one calendar event from the last 60 days or the next 30.
  3. Event tag links to the event page; the feed can be filtered to one event to see everyone's photos from it.
  4. Likes (♥) only for now; no comments yet (they need more moderation).
  5. Moderation: any member can report a post; the site admin is emailed; admins can hide any post from the feed; authors can delete their own posts.
  6. Profiles show the member's recent posts that you're allowed to see.
  7. Not yet: tagging other people (consent first), comments, automatic activity items (e.g. "started a dynamic"), and showing member photos on the public event page.
