Decisions for you

  1. Cover image shows across the top of every profile (desktop and phone) with the profile photo overlapping it, like Facebook and FetLife. No cover: a plain dark band.
  2. Sections as tabs (About · Kinks · Going to · Posts) so long profiles don't scroll forever.
  3. Clickable items: roles, orientation, gender, body type, position, looking for, kinks, interests and city link to Members filtered by that item.
  4. Search only uses what people show to all members. A hidden or connections-only answer is never matched, so searching can't reveal it.
  5. Filters: name, role, looking for, orientation, gender, body type, position, kinks, age range, city, "has a profile photo", "people I follow". Sort by newest or name.
  6. Members only, and blocked members never appear either way.
